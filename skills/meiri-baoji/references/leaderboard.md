# 薄肌教练排行榜

排行榜是可选功能。只有用户明确同意加入并上传分数时才使用。原始饮食、训练、体重、照片和健康数据继续留在本地 `baoji/`；MCP 只接收排行榜成员标识、0–100 分、规则版本和幂等键。

## 每天的流程

1. 调用 `get_leaderboard_definition`，读取当前周期的全部维度、自然语言标准和 `criteria_version_id`。
2. 依据本地记录和每个维度的标准直接给 0–100 分。MCP 负责分发规则和存分，不替你计算热量、步数、体重变化等原始健康指标。
3. 资料不足时先问用户。仍不足就不猜、不把未知记成 0，也不要提交当天分数。
4. 用 `submit_daily_update` 一次提交当前全部维度。每项都带本次读取到的 `criteria_version_id`，并生成一个不会重复的 `idempotency_key`。
5. 不传日期或时区。服务端按排行榜唯一时区归档；当天再次提交会覆盖当天最终分数。

## 已确认默认规则

### 饮食分

- 按用户已确认的个性化饮食计划、目标和现实约束评分，不套统一热量或禁忌。
- 明显不健康行为发生时，饮食分最高 50 分。

### 运动分

- 按用户已确认的训练、活动和恢复计划评分。
- 计划休息日默认 60 分；如果按计划完成主动恢复，可以依规则上调。
- 明显不健康行为发生时，运动分最高 50 分。

### 薄肌分

- 默认 `四舍五入(饮食分 × 50% + 运动分 × 50%)`。
- 任一组成分未知时不要提交薄肌分。
- 出现明显不健康行为时，相关单项以及薄肌分最高 50 分。

这些是已确认的默认规则。排行榜创建者可以用一段自然语言发布新版标准；新版只从下一周周期生效。每次打分都以 MCP 返回的当前版本为准，不把本地旧副本当成最新规则。

## 排名

- 日榜使用当天最后一次提交后的最终分。
- 周榜把本周每一天的最终分累计起来，不求平均。
- 默认查看薄肌分，也可以指定其他维度。

分数只用于趋势和轻量互动，不是健康诊断或人格评价。出现进食障碍迹象时停用评分，不上传分数，并建议寻求专业帮助。
