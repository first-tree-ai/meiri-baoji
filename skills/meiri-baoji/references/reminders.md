# 提醒

提醒由 openTag 的定时任务触发。每次触发都是你的一轮工作，所以每条都可以结合主人当天的情况现写，不用预存文案。

## 为什么要排班

主人不喜欢每天同一时间、同一句话。cron 的时间是固定的，所以用一个固定的「每日排班」任务，每天早上决定当天的随机时间，再创建一次性提醒。

## 开启

在和主人的 IM 对话里运行（定时任务会发回当前这个对话）：

```bash
opentag self schedule create --name 薄肌排班 --timezone <主人的 IANA 时区> --cron "30 6 * * *" \
  --prompt "今日提醒排班：读 baoji/reminders.md，按「排班任务」一节执行。这是定时任务，不是主人发来的消息。"
```

如果现在已经过了当天的排班时间，手动执行一次「排班任务」，否则今天就没有提醒。用 `opentag self schedule preview --cron "30 6 * * *" --timezone <时区>` 确认时间对不对。

## 排班任务

1. 运行 `opentag self schedule list`，删掉已经过期的「薄肌提醒」。
2. 看下面的时段表。今天请假或暂停就到此为止。
3. 给每个时段在窗口内随机选一个时间，创建一次性任务：

```bash
opentag self schedule create --name "薄肌提醒 午饭" --at "2026-11-06T12:17:00+08:00" \
  --prompt "薄肌提醒（午饭）：读 baoji/playbook.md 和今天的记录，给主人发一条短提醒。这是定时任务，不是主人发来的消息。"
```

排班这一轮本身不要给主人发消息，只说一句「今天的提醒排好了」也算打扰。

## 发提醒时

- 一句话，轻松，每次换个说法。看最近几天的对话，别重复。
- 结合实际：这餐已经打过卡，就别再催，换成夸一句或说点别的；昨晚睡得少，语气就体贴点。
- 不要总以问句结尾。
- 晚上最后一个时段：结算今天的薄肌分，给总分、段位和明天最值得改的一件事，先夸做得好的地方。

## 时段表

这是默认值，请按主人的实际作息改。比如主人常常 10 点才到家吃饭，晚饭和日结都要往后挪。

| 时段 | 窗口 | 内容 |
|---|---|---|
| 早餐 | 07:40–08:30 | 喝水、吃早餐、打卡 |
| 午饭 | 12:00–12:50 | 吃午饭、打卡 |
| 下午 | 15:00–16:00 | 喝水、加餐 |
| 运动 | 17:00–18:00 | 运动。休息日换成一句别的 |
| 晚饭 | 18:40–19:30 | 吃晚饭、打卡 |
| 日结 | 21:00–21:40 | 结算当天 |

主人定了其他规矩也放进来，比如「14 点后不喝咖啡」，就在 13:00–13:40 加一个咖啡提醒。

## 暂停和调整

- **改时段：** 直接改上面的表，第二天生效。
- **暂停几天：** 在这里写下「暂停到某日」。排班任务看到就不排了。
- **全部关掉：** `opentag self schedule pause <id>` 暂停排班任务，并删掉当天还没发的提醒。
