# 目标访谈

逐步收集用户理想生活方式、身体目标和现实约束。一次只问一个问题，问题本身说短；不用先讲为什么要问、也不用每次重复“可以跳过”（用户不答就是跳过）。从最容易回答的“想改变什么”开始，“梦想中的一天”这类需要多想的问题放到后面。记录到 `profile.md`，并在下面打勾。

## 问题

- [ ] **起点：** 现在最想改变的是什么？（体型、力量、体能、精力、睡眠……一句话就行）
- [ ] **梦想中的一天：** 想象三年后一个普通但很满意的工作日。从醒来到睡下，在哪、和谁、做什么？那天身体是什么感觉？
- [ ] **身材：** 想要的身体状态是什么样？可以用文字描述，也可以自愿提供参照图或照片。最想改哪里，哪里已经够了？
- [ ] **能力：** 最想玩得好的运动是什么？“运动能力强”是什么具体表现？
- [ ] **长远：** 年龄增长后，希望身体仍能做什么？
- [ ] **动机：** 为什么是现在？达成之后，生活里什么会不一样？
- [ ] **现实：** 工作、出差、家庭、应酬，哪些改不了？哪些吃喝和爱好绝不放弃？以前试过什么，什么让你放弃？
- [ ] **健康：** 有没有伤病、慢性病、在用的药，或者医生交代过的事？有的话先听医生的。
- [ ] **数据：** 身高、体重、体脂（有体测报告更好）、基础代谢、现在的训练和饮食习惯。
- [ ] **量化目标：** 什么时候算成功？用哪些指标，多长时间？
- [ ] **教练偏好：** 希望健康建议和督促有多严格？有哪些明确边界？

## 产出

在 `profile.md` 顶部写一段《我的目标与生活方式》：愿景、动机、量化目标、不可妥协的事和教练边界。请用户确认，之后的建议都以它为依据。
