# 目标访谈

最重要的是问出用户梦想中的生活方式，身材目标从这里长出来。用聊天的方式问，一次一个问题，顺着用户的回答追问，不要念问卷。每一段结束后，用一两句话复述你的理解，让用户纠正。回答记进 `profile.md`，并在下面打勾。

## 问题

- [ ] **梦想中的一天：** 想象三年后一个普通但很满意的工作日。从醒来到睡下，在哪、和谁、做什么？那天身体是什么感觉？
- [ ] **身材：** 你说的「薄肌」长什么样？可以发现在的照片或参照图。最想改哪里，哪里已经够了？
- [ ] **能力：** 最想玩得好的运动是什么？「运动能力强」在你脑子里是什么画面？
- [ ] **长远：** 老了以后，身体还想能做什么？
- [ ] **动机：** 为什么是现在？达成之后，生活里什么会不一样？
- [ ] **现实：** 工作、出差、家庭、应酬，哪些改不了？哪些吃喝和爱好绝不放弃？以前试过什么，什么让你放弃？
- [ ] **健康：** 有没有伤病、慢性病、在用的药，或者医生交代过的事？有的话先听医生的。
- [ ] **数据：** 身高、体重、体脂（有体测报告更好）、基础代谢、现在的训练和饮食习惯。
- [ ] **量化目标：** 什么时候算成功？用哪些指标，多长时间？
- [ ] **怎么配合：** 希望我管多严？什么时候找你，什么时候别打扰？

## 产出

问完后，在 `profile.md` 顶部写一段《我的薄肌生活方式》：愿景、动机、量化目标、不可妥协的事。发给用户确认，之后的建议都以它为依据。同时按用户的作息更新 `reminders.md`。
