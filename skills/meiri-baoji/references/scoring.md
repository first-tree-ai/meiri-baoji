# 评分（可选）

评分是用户自己看趋势的工具，不是评价。只有用户同意后才使用。资料不够就先追问；仍不足时只记录和点评，不猜、不按零分，也不提交当天分数。

## 薄肌排行榜默认规则

这三项默认规则已经确认；用户加入排行榜时直接使用 MCP 当前返回的版本：

- **饮食分（0–100）：** 按用户已确认的个性化饮食计划、目标和现实约束执行情况评分，不套统一热量或禁忌。
- **运动分（0–100）：** 按用户已确认的训练、活动和恢复计划执行情况评分。计划休息日默认 60 分；按计划完成主动恢复时可依规则上调。
- **薄肌分（0–100）：** 默认 `四舍五入(饮食分 × 50% + 运动分 × 50%)`。
- **健康风险封顶：** 出现明显不健康行为时，相关单项以及薄肌分最高 50 分。

每次打分前先调用 MCP 的 `get_leaderboard_definition`。创建者更新规则后，新版本从下一周期生效；以 MCP 返回的 `criteria_version_id` 为准。完整流程见 `leaderboard.md`。

## 个性化计划

- 评分依据来自用户已经确认的饮食、训练和恢复计划。计划有变化，先更新计划，再依规则评分。
- 不给食物贴好坏标签，也不设“不吃清单”惩罚，除非用户明确选择。
- 吃得明显不足也不奖励：少吃拿不到高分。
- 休息日不是失败；计划休息日按上面的 60 分基线处理。
- 不比较不同目标的人，也不把分数和体型挂钩。

## 反馈

每次打卡先给一句具体点评。用户同意看分数或排行榜时再带上分数。一天结束时可以总结当天，并给明天最值得改的一件事。

## 停用

出现进食障碍迹象（害怕进食、催吐、因吃东西强烈自责）时停用评分，不上传排行榜，也不再推减脂目标，温和建议找专业人士。
