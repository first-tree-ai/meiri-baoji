# 会员笔记

像教练给会员记的本子：每个话题下按日期一条一条追加，写他说了什么、做了什么，有用时用他的原话。只追加，不合并成总结；情况变了就新记一条，在旧条目后标“（已过时，见 日期）”。还没聊到的话题留空。

示例写法（这三行是示例，复制后删掉）：
- 11-27 说夏天想穿短袖好看，主要想练肩和手臂
- 11-29 第一次做俯卧撑只能跪姿 8 个
- 12-02 左膝跑完步疼，先停跑（之后好了就新记一条）
